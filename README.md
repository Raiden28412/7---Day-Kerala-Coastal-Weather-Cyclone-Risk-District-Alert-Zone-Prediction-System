# 7---Day-Kerala-Coastal-Weather-Cyclone-Risk-District-Alert-Zone-Prediction-System
A Machine learning(Random Forest algorithm) Streamlit application for 7- Day coastal cyclone risk prediction and district alert zones tailored for Keralam fisherfolk
## Features 
**7-Day Weather Forecasting:**Predicts meterological conditions including surface pressure and wind
**Cyclone Risk Assestment: ** Evaluates atmosphere data to flag potential cyclone warnings
**District Alert Zones:** Categorizes alerts by coastal districts to keep local communities safe
**Interactive UI:**Simple user friendly streamlit interface for easy use
## Tech
**Python**(used python libraries Pandas,Numpy,Scikit-learn,joblib)
**Streamlit**(For frontend UI)
**Machine Learning:** Random Forest Model ('kerala_weather_model.pkl)
